# Contributing to CinderBlock

Thank you for your interest in contributing to CinderBlock.

## Contribution Policy

**At this time, we are not accepting unsolicited pull requests or direct commits to this repository.**

This repository is maintained strictly by the core developers/maintainers of The Cinder Project. Any commits, pull requests, or code modifications by individuals who have not been explicitly invited as collaborators or granted prior written permission will be **rejected and closed immediately**.

### Why this policy?

CinderBlock is a security-focused content blocking engine — it handles network request filtering, scriptlet injection, and rule processing. An unreviewed external change to these areas isn't just a process risk, it's a real attack surface. Until CinderBlock's contribution review process is more established, we're keeping the codebase strictly maintainer-controlled to protect user trust.

### How to get involved

If you're interested in contributing code, reach out to the project maintainers first. Contact options:

- **Owner / Maintainer / Main Developer:** [Sabeeir Sharrma](https://github.com/SabeeirSharrma)

Only after being officially invited as a collaborator, joining our organization, or receiving explicit permission from the core team may you begin submitting changes.

For details on our contribution process across all Cinder Project repos, see the [CPAC Contributing Guide](https://github.com/SabeeirSharrma/cpac/blob/main/CONTRIBUTING.md).

### Bug reports and suggestions

You don't need prior permission for this part — bug reports, feature suggestions, and general feedback are welcome through either:

- Opening a new [issue](https://github.com/SabeeirSharrma/CinderBlock/issues) on this repository
- Our [Discord server](https://discord.com/invite/3ZMtEgJjFT)

### Filter list contributions

CinderBlock uses filter lists maintained by the community. If you find broken website functionality or want to suggest filter list improvements:

- Report issues with existing filter lists via [issues](https://github.com/SabeeirSharrma/CinderBlock/issues)
- Custom filter lists can be added via the CinderBlock dashboard using any public URL

### Translations

Translation support will be added in a future release. CinderBlock does not currently ship with its own i18n system — it will integrate with Ember's i18n when available.
